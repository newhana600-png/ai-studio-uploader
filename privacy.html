1. 사용하는 정보

이 도구는 Google OAuth로 운영자 본인이 허용한 YouTube 계정에 접근하며, 다음 용도로만 YouTube Data API와 YouTube Analytics API를 사용합니다.

  • youtube.readonly: 로그인한 채널의 ID와 이름을 확인해 올바른 채널에 올리는지 대조
  • youtube.upload: 운영자가 만든 영상과 썸네일을 비공개로 업로드
  • youtube: 운영자 본인 채널의 영상 공개 예약·아동용 설정 수정, 재생목록 만들기·정리
  • yt-analytics.readonly: 운영자 본인 채널의 영상별 조회·시청 시간 지표를 읽어 운영 개선에 사용

2. 저장과 공유

  • OAuth 토큰과 채널 ID는 운영자의 PC에만 저장되며 외부 서버로 보내지 않습니다.
  • YouTube 사용자 데이터를 수집·판매·공유하지 않으며, 광고나 다른 목적에 쓰지 않습니다.
  • Google API로 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.
  • 이 도구는 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.

3. 접근 권한 철회와 삭제

Google 계정 권한 페이지에서 언제든 접근을 철회할 수 있습니다. 철회하거나 도구 사용을 멈추면 PC에 저장된 토큰을 삭제합니다.

Privacy Policy · AI Studio Uploader

Effective date: 2026-11-07 (revised: added scopes)

1. Information used

The tool accesses only the YouTube account the owner authorizes through Google OAuth, and uses the YouTube Data API and YouTube Analytics API solely to:

  • youtube.readonly: read the signed-in channel's ID and name to confirm uploads go to the right channel
  • youtube.upload: upload the owner's own videos and thumbnails as private
  • youtube: schedule publishing and update the made-for-kids setting of the owner's own videos, and create and organize the owner's playlists
  • yt-analytics.readonly: read per-video view and watch-time metrics of the owner's own channels to improve the channel

2. Storage and sharing

  • OAuth tokens and channel IDs are stored only on the owner's computer and are never sent to any other server.
  • No YouTube user data is collected, sold, or shared, and none is used for advertising or any other purpose.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • The tool is subject to the YouTube Terms of Service and the Google Privacy Policy.

3. Revoking access and deletion

Access can be revoked at any time on the Google Account permissions page. When access is revoked or the tool is no longer used, the locally stored tokens are deleted.
